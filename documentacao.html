Guia de Instalacao, Operacao e Arquitetura do Sistema

🚀 Como Instalar e Configurar

  • 1. Acesse o Instalador: Va para o seu navegador e digite a URL da pasta (Ex: seudominio.com/claude/install_claude/install.php).
  • 2. Insira as Credenciais: Preencha o formulario com o Endpoint Base e a Chave da API que voce possui.
  • 3. Conclua: O script criara o arquivo estrito config.json de forma automatica, conectando a interface ao proxy.
  • 4. Seguranca: Apos verificar que o chat esta funcionando, acesse o servidor e apague o arquivo install.php para evitar que outras pessoas alterem sua chave.

🧠 Como o Sistema Funciona (Stateless)

O sistema abandonou o uso de banco de dados MySQL para garantir extrema velocidade e baixo consumo no servidor.

  • Sem Banco de Dados: O historico das conversas e salvo instantaneamente no navegador do usuario usando localStorage.
  • Fatiamento de Memoria: Apenas as ultimas X mensagens (baseado no "Contexto" selecionado na tela) sao enviadas para a API a cada requisicao, prevenindo estouros no limite de Tokens.
  • Proxy Seguro: Toda comunicacao com a Anthropic passa pelo api.php, ocultando sua chave de API do usuario final.

🖼️ Processamento de Anexos

A arquitetura foi desenhada para otimizar arquivos antes que cheguem na API:

  • Imagens (GD Library): O servidor comprime automaticamente JPGs, PNGs ou WEBPs grandes. Reduz a resolucao para um maximo de 512px e injeta a qualidade a 65%, prevenindo erros de Proxy (Erro 422 - Payload Too Large).
  • Arquivos PDF (pdftotext): O script processa nativamente PDFs no servidor Linux via shell_exec, extrai o texto puro e limpa caracteres invisiveis antes de acoplar na variavel de envio para a API.
